# Сайт ремонтной компании на WordPress

Кастомная тема WordPress `remont` для компании по ремонту квартир под ключ.
Визуальная логика (композиция, типографика, ритм секций) перенесена с референса bernic.ru —
подробности и подтверждённые наблюдения в [docs/design-spec.md](docs/design-spec.md).

## Что внутри

| Путь | Назначение |
|---|---|
| `compose.yaml` | WordPress 7.1 (PHP 8.3, Apache) + MariaDB 11.4 + служебный WP-CLI |
| `.env.example` | Шаблон настроек; рабочий `.env` в репозиторий не попадает |
| `theme/` | Тема WordPress (подключена в контейнер, правки видны сразу) |
| `seed/` | Скрипты наполнения сайта: `seed.php` (услуги, FAQ, страницы, меню) |
| `seed/sinergiya.php` | Реализованный проект «Синергия»: фото объекта, страница, фото главной и услуг |
| `seed/portfolio.php` | Дизайн-проекты «Частный дом в Повадино» (2M Architects), ЖК «Эвер» и ЖК «Вереск» (ТИХО) — визуализации |
| `seed/images/<проект>/` | Фото по проектам, без метаданных; источники — в `SOURCES.md` каждой папки |
| `scripts/setup.ps1` | Первый запуск: контейнеры, установка WordPress, тема, демо-контент |
| `scripts/reset.ps1` | Полный сброс локального сайта (с подтверждением) |
| `brand/DOMO-original.png` | Исходный файл логотипа; версия для сайта — `theme/assets/img/logo-domo.png` (прозрачный фон, графит #171815) и светлая `logo-domo-light.png`. Значок сайта (favicon) — `brand/favicon-512.png`, `brand/favicon.ico`, в теме `site-icon.png` |
| `docs/design-spec.md` | Спецификация дизайна по исследованию референса |

## Запуск (Windows + Docker Desktop)

1. Запустите Docker Desktop.
2. Откройте PowerShell в папке проекта.
3. Если файла `.env` нет — скопируйте `.env.example` в `.env` и задайте пароли.
4. Выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
   ```

5. Сайт: <http://localhost:8080>, админка: <http://localhost:8080/wp-admin>
   (логин и пароль — `WP_ADMIN_USER` / `WP_ADMIN_PASSWORD` в `.env`).

Скрипт можно запускать повторно — он не создаёт дублей.

## Остановка и повторный запуск

```powershell
docker compose stop      # остановить (данные сохраняются)
docker compose start     # запустить снова
docker compose logs -f wordpress   # журнал веб-сервера
```

## Обновление WordPress

Версия закреплена в `compose.yaml` (`image: wordpress:7.1-php8.3-apache`). PHP 8.3 выбран, потому что он
есть на хостинге Beget. Порядок обновления:

1. Резервная копия базы и файлов в `backups/` (папка не попадает в Git).
2. Поменять тег образа в `compose.yaml` и выполнить `docker compose up -d wordpress`.
3. Обновить ядро и базу: `docker compose run --rm wpcli wp core update --version=X.Y.Z`,
   затем `wp core update-db` и `wp core verify-checksums`.

Ядро в томе `wp_data` при смене образа само не обновляется, поэтому шаг 3 обязателен.

## Сброс (удаляет данные!)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\reset.ps1
```

Удаляет базу, загруженные файлы и заявки локального сайта. Тема и демо-фото остаются.
Скрипт попросит ввести `DELETE` для подтверждения.

## Цвета

Палитра DOMO задана в самом начале `theme/assets/css/main.css` (блок `:root`):
молочный `#F7F6F2` (фон), бежевый `#EAE6DE` (чередующиеся секции), графит `#171815` (текст и
контрастные кнопки), шалфейный `#B9CF91` (главные кнопки и акценты), серый `#77786F`,
белый `#FFFFFF` (карточки и формы), `#D9D7D0` (разделители). Компоненты используют только эти
переменные, поэтому цвет меняется в одном месте.

Правила читаемости (проверено автоматическим аудитом контраста WCAG AA):
- шалфейный — только фоном под графитовым текстом (10.5:1), как цвет текста на светлом фоне не используется;
- для мелкого вторичного текста — затемнённый серый `#64655D` (≥4.7:1), сам `#77786F` — для рамок полей и подсказок;
- ошибки формы — без красного: графитовый жирный текст со значком «!».

## Где что редактировать в админке

- **Внешний вид → Настроить → «Сайт ремонтной компании»** — телефон, почта, регион, график,
  тексты и фото главной, факты, этапы, преимущества, блок контроля качества.
  Списки задаются по строке: `Заголовок | Текст`.
- **Внешний вид → Настроить → Свойства сайта** — логотип и название.
- **Внешний вид → Меню** — главное меню и меню «Компания» в подвале.
- **Услуги** — страницы видов ремонта: текст, отрывок, фото, «Что входит», связь с калькулятором.
- **Портфолио** — проекты: характеристики, галерея (кнопка «Выбрать фотографии»), вид ремонта.
- **Вопросы и ответы** — FAQ (порядок — поле «Порядок»).
- **Настройки → Калькулятор и заявки** — ставки за м², коэффициенты состояния, доп. работы,
  разброс оценки, демо-режим, email для уведомлений.
- **Заявки** — все заявки с сайта, статус «Новая / В работе / Закрыта», счётчик новых в меню.

## Как устроены формы

- Поля: имя, телефон, тип ремонта, площадь, комментарий.
- Проверка на сервере, защита от CSRF (nonce WordPress), ловушка для ботов, отсечение слишком
  быстрой отправки, лимит 5 заявок за 15 минут с одного адреса (IP хранится только в виде хеша
  во временном кэше).
- Заявка сохраняется в WordPress; сообщение об успехе показывается только после сохранения.
- Работает и без JavaScript (обычная отправка с возвратом на страницу).
- Данные не отправляются внешним сервисам. Письмо администратору — только если указан email
  в настройках и на сервере настроена почта.

## Калькулятор

Тариф ремонта × площадь (ползунок до 1000 м²) = одна фиксированная сумма, без диапазона.
Под тарифами показывается состав работ выбранного тарифа.
Кнопка «Передать расчёт в заявку» заполняет форму и прикладывает сводку к заявке.

Тарифы, ставки (за м²), подзаголовки и состав работ редактируются в **Настройки → Калькулятор и заявки**.
По умолчанию: Эконом — 40 000 ₽/м², Стандарт — 50 000 ₽/м², Премиум — 60 000 ₽/м².

## Структура темы

```
theme/
  style.css, functions.php
  header.php, footer.php, front-page.php, page.php, index.php, 404.php
  archive-service.php, single-service.php
  archive-project.php, taxonomy-repair_type.php, single-project.php
  page-templates/about.php, page-templates/contacts.php
  template-parts/   — герой, услуги, слайдер проектов, карточки, калькулятор,
                      этапы, FAQ, форма, CTA, шапка внутренних страниц
  inc/              — setup, post-types, meta-boxes, customizer, calculator,
                      leads, seo, assets, template-tags
  assets/css/main.css  — все стили, токены дизайна в :root
  assets/js/           — main.js (меню, слайдер, галерея, форма), calculator.js
  assets/fonts/        — Russo One, Tenor Sans, Montserrat (SIL OFL)
```

## Что заменить перед запуском

- Название компании, логотип, телефон, почту, регион, график, юрлицо и ИНН.
- Проекты с пометкой «Визуализация» — дополнить реальными фото после реализации (снять отметку в карточке проекта).
- В проекте «Синергия» указать площадь, сроки, район и вид ремонта (сейчас стоит «Дизайнерский»).
- Текст «О компании», ответы FAQ про замер и гарантию, политику конфиденциальности (через юриста).
- После проверки контактов включить «Контакты проверены» в настройках — тогда они попадут в микроразметку.
