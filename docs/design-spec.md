# Спецификация дизайна (по исследованию bernic.ru, 19.10.2026)

Источник: скриншоты главной и внутренних страниц bernic.ru, сделанные headless-Chrome
(1440×900 и 390×844), плюс вычисленные стили (getComputedStyle) и CSS-переменные сайта.

Важно: bernic.ru — сайт производителя домов и бань из морских контейнеров, не ремонтной
компании. Переносится дизайнерская логика (сетка, иерархия, ритм секций, типографика,
работа с фото), а не тексты, фото, логотип или шрифты с ограниченной лицензией.

## Подтверждённые наблюдения

**Типографика**
- Заголовки H1/H2: широкий геометрический акцидентный шрифт Furore (фолбэк в их CSS — Russo One),
  ВЕРХНИЙ РЕГИСТР, regular, межбуквенный ~0.02em. H1 ≈ 66px, H2 ≈ 48–52px, H3 карточек ≈ 30px.
- Текст абзацев: Tenor Sans (антиква-гротеск с «гуманистичным» видом), 17–19px, высокий интерлиньяж.
- UI (меню, кнопки, подписи, «надзаголовки»): Montserrat; надзаголовки — 11–12px, капс,
  разрядка ~0.2em, цвет приглушённый.
- Ссылки-действия: капс Montserrat + длинная тонкая стрелка «⟶» справа.

**Цвет (CSS-переменные сайта)**
- Акцент «ржавый терракот» #ae5127 (hover #96431f); тёмно-коричневый текст заголовков #2a1e16;
  текст #4a3f38; приглушённый #6b605a; светлый «бумажный» фон #f7f3ee; графит #1c1c1c/#141414;
  кремовый #e9d2b7; границы #e7dfd5. Радиусы маленькие (3–5px), тени — плоские смещённые.

**Сетка и ритм**
- Контейнер ~1300–1600px с полями 64px; секции чередуют фоны: белый → бумажный → терракот → графит.
- Большие вертикальные отступы между секциями (~100–120px).

**Главная (последовательность)**
1. Шапка: белая, 63px, логотип слева, меню капсом с выпадающими мега-меню (фото-карточки),
   кнопка-контур «Каталоги», телефон, кнопка-заливка справа. Шапка «липкая» при прокрутке.
2. Герой на всю высоту экрана: фото, затемнение, огромный H1 капсом слева, подзаголовок,
   кнопка + текстовая ссылка со стрелкой.
3. Тёмная полоса фактов (5 колонок: жирный факт + подпись).
4. «Что мы строим»: мозаика фото-карточек (2 + 3), текст поверх фото снизу: цена капсом,
   заголовок, описание, «СМОТРЕТЬ ⟶».
5. Горизонтальный слайдер проектов: первая карточка — терракотовый блок с призывом,
   далее фото с названием поверх, описание, характеристики через вертикальные разделители,
   цена в плашке; навигация «⟵ НАЗАД  ДАЛЬШЕ ⟶».
6. Конфигуратор на бумажном фоне: строки «заголовок слева / варианты справа», разделители.
7. Видео-ряд вертикальных карточек.
8. Форма заявки: слева заголовок + нумерованные шаги в терракотовых кружках, справа белая карточка формы с тенью.
9. Три колонки преимуществ с верхней линией, заголовок H3 капсом, текст, ссылка-стрелка.
10. Сплит-блок: фото слева / графитовая панель справа с цифрами и белой кнопкой.
11. Терракотовый блок со статистикой в сетке 2×2.
12. Чередующиеся «текст + фото» блоки, логотипы партнёров, финальный тёмный CTA.
13. Подвал на бумажном фоне: 4 колонки ссылок с заголовками капсом, телефон, форма «Перезвоните мне».

**Внутренние страницы**
- Каталог/карточка: герой с фото, хлебные крошки, H1, «плавающая» карточка с ценой справа,
  чипы-фильтры, сетка карточек 3 в ряд, многошаговый калькулятор с липкой сводкой справа,
  таблица сравнения, FAQ-аккордеон (+/−) на бумажном фоне.
- О компании: герой-фото, полоса фактов, «кто мы» + список принципов справа.
- Процесс: бумажный герой (текст + фото), карточки этапов 4 в ряд с терракотовым заголовком.
- Контакты: бумажный герой, кнопка-телефон, блок менеджера, адрес, реквизиты.

**Мобильная версия (390px)**
- Шапка: бургер слева, логотип, иконка телефона. Меню — полноэкранная панель с аккордеоном
  разделов и закреплёнными кнопками «Позвонить / WhatsApp» снизу.
- Карточки в одну колонку, слайдеры с прокруткой, H1 ≈ 36px.

## Предположения (не проверены)
- Точные анимации появления и поведение слайдеров при свайпе не изучались покадрово.
- Видео-блоки не воспроизводились.
